# Auditing stanpumpR's models against nlmixr2lib

Steven L. Shafer, 2026-11-23: the nlmixr2lib review is meant to find the drugs, models and papers stanpumpR should bring in, and it "would also be useful as an audit of the PK models in stanpumpR". This page records that audit. It is written by hand. The tables it reads (`summary.md`, `shared-papers.csv`, `shared-parameters.csv`, `candidate-papers.csv`) are generated by `data-raw/nlmixr2libCrossCheck.R`, here against nlmixr2lib 05d1c08 (2026-11-22).

The audit has two parts:
1. **Numbers.** Did both libraries read the same numbers from the same paper?
2. **Currency.** Does nlmixr2lib hold a model of one of stanpumpR's drugs, fitted to many more patients, that stanpumpR has not considered?

nlmixr2lib's transcriptions are leads, like any other reader's (AGENTS.md, *Other libraries' transcriptions ... are leads*). A disagreement is settled on the PDF, never by taking nlmixr2lib's value.

## What changed in the script (2026-11-23)

- **Papers the code cites with no digest card are now compared.** Until today the cross-check compared only papers with a digest card. Twenty-four papers that stanpumpR's own `R/` files cite by DOI had no card, and so were never compared at all. Piperacillin's source, Kong 2025, was one of them. These papers are now compared with the files that cite them; 18 are in this run's tables. `shared-papers.csv` gives them an empty `card` and the DOI in `citation`.
- **Logit parameters are matched as the fraction.** nlmixr2lib often writes a fraction `p` as `log(p/(1-p))`, so the script read the odds, `p/(1-p)`, and never found it. Bjornsson 2023's sublingual F of 0.14 was read as 0.1628. A parameter named `logit...` is now matched as the fraction stanpumpR prints. Buprenorphine's F (0.14) and pathway split (75.9%) match exactly, and so does diamorphine's depot fraction (Cai 2025).

### Findings that need action

1. **Sotalol: the source disagrees with itself.** Yellepeddi 2025 (PMID 39749676, PMC12001255, not yet in the archive and with no digest card) gives two sets of final estimates:
   - Table 2: creatinine-clearance exponent on CL 0.7, weight exponent on Vc 1.1, ka 0.2 /h, F_oral 1.6. These are the values `R/drugs_sotalol.R` uses (it takes absorption from the FDA review instead).
   - Table 3, the bootstrap table's "final parameter estimate" column: weight exponent 1.2 and F_oral 1.5.
   - nlmixr2lib: CrCl exponent 0.65, ka 0.16 /h, weight exponent 1.2.

   These look like unrounded values from the NONMEM control stream (the paper's Data S1), which would settle it. The paper and its Data S1 are in `papers/pending-work.csv`. The effect is small: 0.65 against 0.7 changes clearance by 2% at 60 mL/min and 6% at 30. But the weight exponent is printed twice with different values.
2. **Rocuronium and sugammadex come from different sources.**
   - `R/drugs_rocuronium.R` is Plaud 1995 (card `PMID_7648768`): fixed per-kilogram rate constants, no covariates.
   - `R/drugs_sugammadex.R` is Kleijn 2011, whose model fits rocuronium, sugammadex and their complex jointly. As nlmixr2lib reads it, that model has a rocuronium clearance that falls with age (-0.00678 per year from 43), a term not found in stanpumpR's Kleijn card.

   stanpumpR therefore draws rocuronium from one study and the drug that binds it from another. **Decided by Shafer on 2026-11-23: rocuronium moves to Kleijn 2011's model** (its own pull request).
3. **Lorazepam's disposition comes from six volunteers.**
   - `R/drugs_lorazepam.R` uses Nielsen-Kudsk's six healthy volunteers.
   - Its header already calls Barr 2001 (24 surgical ICU patients, Shafer a co-author) "the natural replacement".
   - The cross-check confirms Swart 2004 (critically ill adults) was transcribed the same by both libraries.

   **Decided by Shafer on 2026-11-23: lorazepam moves to Barr 2001** (its own pull request).
4. **Buprenorphine:** nothing to change. Once the script read the logits correctly, Bjornsson 2023's sublingual F (0.14 at 16 mg) and pathway split (75.9%) agree with the card. The one remaining unmatched term is the opioid-use-disorder shift on the weekly depot, which stanpumpR does not offer.

Each is a candidate for its drug's model selector (AGENTS.md, *The program chooses the model*), as a new candidate whose population is recorded, or as a cross-check. ## What happens next

- **Sotalol:** the paper and its supplement are listed in `papers/pending-work.csv`. When they arrive, the control stream settles which estimates are final.
- **Rocuronium and lorazepam:** replaced, each in its own pull request.

- **The weekly routine:** it reruns the script, so this audit's tables stay current. This page is updated by hand when a finding is settled.
