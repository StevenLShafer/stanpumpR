# Vuong 2025, ESM1: fluconazole popPK supplement (NONMEM control stream and simulation code)

## Study
Supplement to the pooled population PK analysis of intravenous fluconazole in 177 critically ill adults (main paper digest: `PMID_41085604.md`). Contents: titles of Figures S1-S17 (imputed creatinine distributions, observed concentration versus time per centre, goodness-of-fit, pcVPCs per centre and by CRRT status, probability of target attainment of fAUC0-24 200 mg h/L against weight with and without CRRT, fAUC0-24 over time for standard versus optimised dosing, eGFR and weight distributions of the virtual population); the NONMEM control stream; the R code for the virtual population and dosing; and Table S1.

## Model and parameters
Control stream (run001, imputation 01, dataset 01): ADVAN13, TOL 9, three compartments in the code (central, peripheral, and an AUC accumulator, so two PK compartments). Estimation FOCE-I with interaction. Structure:

- CL off CRRT = THETA(2) x (CKDEPI/80)^THETA(6); eGFR is CKD-EPI, "CKDEPI01".
- CL on CRRT = THETA(1), with no covariate, the total of CLr and CLd.
- V1 = THETA(3) x (BW/80)^THETA(7).
- Q = THETA(4); V2 = THETA(5); K = CL/V1; K12 = Q/V1; K21 = Q/V2.
- Residual error: proportional, SIGMA 0.0275 (an SD of 16.6%), additive fixed to 0. Combined as W = sqrt(SIGMA(1,1) IPRED^2 + SIGMA(2,2)).
- Units are not stated in the control stream; the main paper's Table 2 gives L/h and L.

Dosing code (simulation, R): optimised regimen, with loading dose by weight band and maintenance from day 2. On CRRT: load 1000 mg (BW 60 kg or under), 1200 (60-80), 1400 (80-100), 1600 (100-120), 1800 (over 120); maintenance 800 mg. Off CRRT: load 800, 1000, 1200, 1400, 1600 mg in the same bands; maintenance 400 mg. Standard regimen: 800 mg load, then 400 mg. These agree with Table 3 of the main paper as digested.

Virtual-population code: 1000 patients, weights and eGFR sampled from the empirical distributions, 10.2% on CRRT throughout and 9% part-time (58.5% of days). Table S1: dose-finding grid of eGFR 5 to 215 mL/min/1.73 m2 in steps of 10 (N 2200) and total body weight 30 to 150 kg in steps of 5 (N 2500).

## Pharmacodynamics and end points
None in this supplement. The target is fAUC0-24 of 200 mg h/L (named in the figure legends S13-S14); no ke0, MEAC or potency ratio, and it is not an opioid paper.

## Covariates
eGFR (CKD-EPI) on clearance off CRRT and body weight on V1, both power functions normalised to 80. The simulation code renames a column FFM to BW in the virtual dataset, but the control stream's covariate is body weight (BW01...BW18 in $INPUT), which the main paper's digest also notes.

## Caveats
- The $THETA values are one imputation's initial estimates, not the published model; the pooled values are the main paper's Table 2.
- Figures S1-S17 were not read (images).
- The R code is partly a fragment (objects such as Fluco_clean_revised are not defined in it).

The repo uses no omega or error terms, as expected for a deterministic typical-value model.
