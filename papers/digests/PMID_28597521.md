# Xue 2017 erratum: Equation 2 (R-warfarin competitive antagonism)

## Study
Not a study. A one-page erratum (Br J Clin Pharmacol 2017;83:1602, doi 10.1111/bcp.13325; no author line) to Xue et al.
2017 (PMID 27763679). It states the authors identified an error in one equation.

## Model and parameters
- Printed (wrong) Equation 2: PD = Emax / (1 + (C_S / (C50_S + (C_R/RIC50)))^-Hill), the R term added to C50_S.
- Corrected Equation 2: PD = Emax / (1 + (C_S / (C50_S x (1 + C_R/RIC50)))^-Hill), i.e. an apparent
  C50_S x (1 + C_R/RIC50).
- The authors confirm the corrected form was the one coded in the NM-TRAN models, so the published estimates belong to it.

```yaml
parameters: []  # an equation correction; no parameter values are given or changed
```

## Pharmacodynamics and end points
No new values. The correction changes the R-warfarin term from additive to multiplicative (competitive antagonism).

None.

the equation was coded correctly.
