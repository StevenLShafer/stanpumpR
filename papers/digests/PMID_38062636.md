# Lee 2024: topiramate serum levels, response and ataxia (Seoul)

## Study
- Retrospective, Seoul National University Hospital, Jan 2017-Jan 2022: 389 adults with epilepsy, 555 serum
  samples at assumed steady state (regimen unchanged ≥ 1 month); inpatient samples excluded.
- Age 46.4 ± 10.9 y; 50.5% of samples male; weight 64.6 ± 17.7 kg (237 samples); 55.3% of samples on enzyme-
  inducing ASMs (carbamazepine, oxcarbazepine, phenytoin, phenobarbital); 76 samples from 53 monotherapy patients.
- Dose 178.4 ± 117.9 mg/day; spot serum 3.9 ± 2.8 mg/L. UPLC-MS/MS, LLOQ 0.25 µg/mL, linear 0.25-50.
- Response: ≥ 50% seizure reduction = sufficient. Adverse events from chart review. ROC for cut-offs.

## Model and parameters
- PopPK: the earlier one-compartment model with first-order absorption and elimination (Bae 2016, ref 10)
  re-estimated on these data (NONMEM 7.5.1, M1 for BQL; pcVPC; bootstrap 1000). Parameter table is in
  supplementary Table S1 (not in this PDF).
- Apparent clearance (p. 428):
  CL/F (L/h) = (1.45 + 1.02·PHT + 0.703·CBZ + 0.419·OXC + 0.376·PB) × (CLcr/90)^0.277 × (DOSE/100)^0.193
  (DOSE in mg/day; indicator variables for each inducer). Inducers raise CL/F by 70%, 48%, 29%, 26%
  (PHT, CBZ, OXC, PB).
- Vd/F scaled by weight (exponent 1); typical value not given in the main text (about 30% lower than the
  previous model). Individual post-hoc estimates: CL/F 2.1 ± 0.8 L/h, Vd/F 82.4 ± 13.3 L (all samples).
- ka: not reported in the main text.

## Pharmacodynamics and end points
- Response did not differ by concentration: insufficient 3.6 ± 2.5 vs sufficient 4.0 ± 2.8 mg/L (p = 0.45);
  response probability saturated at the lowest levels.
- Ataxia (3 events) associated with level: ROC cut-off 6.5 mg/L spot (specificity 83.5%, sensitivity 100%,
  AUC 0.88) and 6.454 mg/L estimated Cmax. Authors recommend levels below 6.5 mg/L.
- Contrasts with the ILAE range 5-20 mg/L (cited).

## Covariates
CLcr (power 0.277), daily dose (power 0.193), each inducer (additive); weight on Vd/F.

## Caveats
Retrospective, samples timed by clinical judgement, sample rather than patient as the unit; only 3 ataxia
events; parameters mostly in the supplement; dose-dependent CL/F is empirical.
