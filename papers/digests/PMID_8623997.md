# Schnider 1996: lidocaine PK for computer-controlled infusion in pain therapy

## Study
13 patients with pain of possibly neuropathic origin, Stanford Pain Clinic, over 3 years. Mean age 45 y
(31-62), 9 women / 4 men, mean weight 66 kg (49-114) (p. 1044). Lidocaine 2% by CCIP (STANPUMP),
targets 1, 3, 5 and 7 ug/mL for 30 min each. Radial arterial samples before and at 2, 4, 6, 8, 10, 20,
30 min of each step; **no washout samples**. GC with nitrogen-phosphorus detector, LOQ 0.05 ug/mL,
CV 1.7%. 291 samples, 11-28 per subject. First 8 patients dosed with parameter set A (Rowland et al.,
venous, bolus data); next 5 with set B (fitted to the first 8); set C fitted to all 13. NONMEM PRED,
naive pooled structural estimates, then IIV estimated with structure fixed; leave-one-out
cross-validation.

## Model and parameters
Two-compartment mamillary model. Weight was significant on all volumes and clearances (linear per kg);
no other covariate (age, sex) improved the model (p. 1047). Table 1 (p. 1047):

|---|---|---|---|---|---|
| V1 | 34.51 L | 0.088 L/kg | 0.101 L/kg | 0.0162 | 53.4 |
| V2 | 60.61 L | 0.4 L/kg | 0.452 L/kg | 0.058 | 33.0 |
| Cl1 | 0.87 L/min | 0.02 L/kg/min | 0.0215 L/kg/min | 0.00148 | 24.5 |
| Cl2 | 2.0 L/min | 0.056 L/kg/min | 0.0589 L/kg/min | 0.00581 | 35.4 |

Set C is the paper's final parameter set (abstract, Results). Performance: set A prospective MDPE +31%,
MDAPE 33% (first 8); set B weighted residuals +0.7% / 10%, cross-validation +1.1% / 12%, prospective
MDPE -6%, MDAPE 15% (last 5); set C weighted residuals +1.7% / 13%, cross-validation +1.9% / 14%.

## Pharmacodynamics and end points
No PD model, no ke0, tPeak or analgesic concentration estimated. Clinical: with set A all 8 subjects had
transient toxicity (perioral dysesthesia, light-headedness, myoclonus) after step changes, no seizures;
highest measured 15.3 ug/mL, 2 min after a step. With set B no side effects. The 1-7 ug/mL targets were
a study design, not a therapeutic range.

## Covariates
Total body weight, linear on all volumes and clearances. Age and gender tested, not retained.

## Caveats
n = 13; naive pooled structural estimates. Arterial sampling (V1 about 5-fold smaller than Rowland's
venous estimate). No washout data, so the authors say the terminal half-life is probably inaccurate and
infusions longer than 2 h may not perform well (p. 1049). Chronic-pain patients, not surgical or
cardiac.

## Verification against stanpumpR
- Transcription: code V1 0.088 L/kg, k10 0.227273 (= 0.02/0.088), k12 0.636364 (= 0.056/0.088),
  k21 0.14, giving V2 0.4 L/kg, Cl1 0.02 and Cl2 0.056 L/kg/min: exactly **parameter set B**, correctly
  transcribed (derived: at 70 kg cl1 1.400 and cl2 3.920 L/min, as the test pins).
- **Discrepancy**: the paper's final, recommended parameters are **set C** (V1 0.101, V2 0.452 L/kg,
  Cl1 0.0215, Cl2 0.0589 L/kg/min), estimated from all 13 patients; the abstract reports only set C.
  stanpumpR uses the interim set B (first 8 patients), and neither the code nor the help says so;
  the help's "central volume of 0.088 L/kg" reads as the paper's model. Set B was prospectively
  validated (MDPE -6%, MDAPE 15%), so it is defensible, but the choice should be stated or set C used.
  Set C at 70 kg (derived): V1 7.07 L, V2 31.6 L, Cl1 1.505, Cl2 4.12 L/min.
- Weight scaling "per kilogram of total body weight" with fixed rate constants (help 7): **matches**.
- tPeak 5 min (code 17; help "time to peak effect is 5 minutes"): **not from this paper**, which
  reports no effect-site data; source unstated in code. Cannot verify here.
- Band 0.5-1.5 ug/mL, typical 1 (code 14-16, CSV row 15): not from this paper (the paper's targets
  were 1-7 ug/mL by design). Not applicable.
- Help's "toxicity above about 5 mcg/mL": broadly consistent with the paper's observation of transient
  symptoms after step increases, but the paper gives no threshold. Cannot verify.
- RA absorption (Simon 2002): not this paper.
