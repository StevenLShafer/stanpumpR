# Du 2020: one-compartment oral digoxin model with SLCO4C1 genotypes (China)

PDF page n = printed page 1798 + n for pages 1-12; 13-15 are 1810.e1-e3; 17 is the corrigendum (2021;43:790).
The corrigendum is also archived on its own as PMID_32798059_erratum.pdf, with its card PMID_32798059_erratum.md.

## Study
Retrospective TDM, Fuwai Central China Cardiovascular Hospital, Jan 2018-Jul 2019. 176 inpatients with cardiac
insufficiency on oral digoxin, 228 concentrations; randomised to modelling (126 patients, 161 observations, 1-3 per
patient) and external validation (50 patients, 67 observations). Table I (rendered; modelling / validation, mean
(range)): men 85 (67.5%) / 35; age 61.05 (22-89) / 59.2 (31-87) y; weight 67.36 (42-107) / 67.80 (52-91.6) kg;
BMI 21.97 / 23.40; SCr 111.31 (28-484) / 90.28 (40-378) umol/L; initial dose 0.125 mg in 84 (66.7%), 0.25 mg in
42 (33.3%). The original Table I printed the doses as "125 ng / 250 ng"; the corrigendum (PDF p17) corrects them
to 0.125 and 0.25 mg. Samples at steady state, sampling times set by clinicians. EMIT (Siemens Viva-E). 16 SNPs
in ABCB1, SLCO4C1, SLCO1B3 (MassARRAY). Phoenix NLME 8.0, FOCE; exponential IIV, additive residual error;
forward inclusion dOFV 6.64, backward 10.83.

## Model and parameters
One compartment, first-order absorption (2- and 3-compartment not better, Table S2). Final model (eq 6-8):
CL/F (L/h) = 5.06 x (SCr/85)^-0.31 x e^(-0.41 COM) x e^(0.37 rs3114660) x e^(0.38 rs3114661), COM = 1 with
spironolactone; each SNP term = 1 for the wild type (rs3114660 CC, rs3114661 GG), 0 for mutant carriers; 85 is
the median SCr (umol/L). V/F 211.82 L, ka 0.88 /h, no weight term.

(derived: both wild type 5.06 x e^0.75 = 10.71 L/h; spironolactone x 0.664.) Bootstrap medians (Table II) close
to estimates. External validation PE 9.62% (CI -1.41 to 20.66), APE 37.30% for the final model (Table III).
MAFs 0.162 (rs3114660) and 0.491 (rs3114661) (Table S1).

## Pharmacodynamics and end points
None; reference interval 0.8-2.0 ng/mL (assay); Table IV gives genotype/SCr/spironolactone dose suggestions.

## Covariates
SCr (power, median 85 umol/L), spironolactone, two intronic SLCO4C1 SNPs (functional role unknown, as the authors
say). BUN collinear with SCr, dropped.

## Caveats
Sparse TDM; the 95% CIs of the SCr and spironolactone effects include zero although the OFV tests were
significant; RSEs printed negative for negative estimates; ka barely identifiable (shrinkage 0.98); creatinine
unit printed "mmol/L" in the text layer of eq 6's description where umol/L is meant (Table I and the corrigendum
print umol/L); SNP biology unknown; single centre.
