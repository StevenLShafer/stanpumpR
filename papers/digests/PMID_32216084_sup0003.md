# Chen 2020 (supplement): Figure S3, individual fits of the final model

## Study
No new study. Individual plots for a "representative sample" of participants of the parent article's population model
(card `PMID_32216084.md`). One tall PDF page.

## Model and parameters
Four panels, each a 4 x 4 grid of participants, x: TADNOM 0-10 h; open circles DV (observed), red solid IPRED, blue
dotted PRED; y: "concentration of SXB in units of ug/mL" (caption), while the legend defines DV/IPRED/PRED as the
concentration "of oxybate".
- A: linear scale, PK visit 1, participants ID 37-52.
- B: linear scale, PK visit 2, ID 37-47 and 49-53 (48 absent, 53 added).
- C: semilog, visit 1, ID 37-52. D: semilog, visit 2, as B.
Most participants show two peaks (doses about 4 h apart), up to about 200 ug/mL; ID 50-53 show a single-dose profile
(one peak, falling to about 10 ug/mL or below by 6-7 h). IPRED follows DV closely; PRED departs more (for example
ID 48 visit 1, ID 51 visit 2 at late times). Which study each ID belongs to is not stated.

## Caveats
- "Representative sample" is not defined; selection method not stated.
- The basis is labelled SXB in the caption but "oxybate" in the legend, the same mixed labelling as the main article
  (Figure 5).
- Semilog panels show steep terminal falls after the second peak in several participants (concentration-dependent,
  as Michaelis-Menten elimination predicts); no half-lives are given.
