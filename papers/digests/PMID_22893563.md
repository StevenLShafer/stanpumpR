# Yuen 2013: duloxetine exposure-response for diabetic neuropathic pain

## Study
Pooled 3 phase III double-blind placebo-controlled 12-week DPNP trials (Eli Lilly). 1139 randomized: placebo
339, 20 mg qd 115, 60 mg qd 344, 60 mg bid 341; 1106 analysed (12,549 weekly-mean pain scores, 11-point NRS).
Mean age ~60 yr (20-89), 54-67% male, ~85% type 2 diabetes. Sparse PK in 2 of 3 trials; each patient's
steady-state concentration (Css) was predicted from the Lobo 2009 population PK model and demographics, not
measured. NONMEM 6 (FOCE / Laplace). Duloxetine t1/2 12.5 h from that PK model.

## Model and parameters
No new PK model (uses Lobo 2009). Descriptive PD model: pain = Base x [1 + PE(1 - e^-C t) + f(d)(1 - e^-K t)],
f(d) = Emax x Css / (EC50 + Css). Table 2 (estimate, SE%), mapping reconstructed from the scrambled text:

## Pharmacodynamics and end points
End point: weekly mean 24-h average pain, 11-point NRS; responder = >= 2-point drop. EC50 ~24 ng/mL on
steady-state concentration; onset rate K 0.44 /week (no ke0 in minutes or hours). Week-12 median pain
decrease (simulated) e.g. 60 mg qd: 2.34 / 3.00 / 4.00 for mild / moderate / severe baseline pain. Placebo
response ~40%; ~65-70% responders at 60 mg qd/bid. Not an opioid paper; no MEAC.

## Covariates
Baseline pain severity (categorical) on Base (descriptive model) and theta1 (proportional odds). Age, sex,
ethnicity, DPNP duration, diabetes type not significant.

## Caveats
Concentrations predicted, not measured; effect is on a chronic weekly scale; very large BSV; Tables 2-3 could
not be mapped with certainty from the text layer (page images not rendered).
