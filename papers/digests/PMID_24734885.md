# Kakara 2014: population PD of statin LDL-cholesterol lowering

## Study
Retrospective electronic-medical-record study, Fukuoka Tokushukai Medical Center,
Japan, Nov 2009-Oct 2011. 378 statin-naive Japanese adults, 2863 LDL-C
concentrations: atorvastatin n=149 (106 M/43 F, median age 62, range 31-89),
pitavastatin n=45 (27/18, age 64, 42-84), rosuvastatin n=184 (119/65, age 61,
27-91) (Table 1, PDF p5/printed 828). Patients <60 mg/dL baseline LDL-C or on
multiple statins excluded. Daily doses: atorvastatin 5/10/15/20 mg, pitavastatin
1/2/3/4 mg, rosuvastatin 2.5/5/7.5/10 mg; most patients on the two lowest doses.
Median dosing periods 362/437/304 days. Baseline (median, range) LDL-C 151
(71-359), 145 (81-232), 157 (78-310) mg/dL. No PK data — effect driven by dose.
Physiological indirect-response (turnover) model, NONMEM 7.2.0 FOCE-INTER, Xpose
4.3.2 / R 2.13.1 / S-PLUS 8.1; bootstrap (1000), pcVPC, NPDE.

## Model and parameters
Indirect response: dLDL/dt = Kin·(1-INH) - Kout·LDL, with Kout = Kin/Baseline;
inhibition INH = Imax·Dose/(ID50 + Dose). Statins share a common Imax with a
separate ID50 each; ezetimibe adds +0.109 to INH (an additive 10.9% fall in Kin),
and baseline falls with age. Final equations (p4/printed 827 text, p5 Table 2):
INH = Imax·Dose/(ID50+Dose) + 0.109·ezetimibe; Baseline(mg/dL) = 152·(age/62)^-0.240;
Kin(mg/dL/day) = 32.8. Values confirmed on the rendered Table 2 (PDF p5):

## Pharmacodynamics and end points
End point is serum LDL-cholesterol (mg/dL), not a concentration of drug. Effect is
indexed to daily dose (no drug PK). Potency ranking by ID50 (dose for 50% of Imax):
rosuvastatin ~ pitavastatin > atorvastatin, but the authors warn ID50 shrinkage is
~40% so only relative, not absolute, potency should be read (p9/printed 833 text).
Common maximum fractional inhibition of synthesis Imax 0.567. Simulated maximum
LDL-C reduction and time-to-maximum (Table 3, PDF p9/printed 832, n=5000, 12 weeks):

- Atorvastatin 5/10/15/20 mg: median reduction 38.4 / 45.3 / 48.4 / 50.6%; time to max 4.3 / 4.4 / 4.4 / 4.4 weeks.
- Pitavastatin 1/2/3/4 mg: 29.5 / 38.8 / 43.1 / 45.6%; 4.1 / 4.3 / 4.3 / 4.4 weeks.
- Rosuvastatin 2.5/5/7.5/10 mg: 38.9 / 46.0 / 49.0 / 50.6%; 4.3 / 4.4 / 4.4 / 4.4 weeks.

Maximum effect reached ~4-5 weeks irrespective of dose. No ke0/hysteresis/MEAC
(not an opioid, no analgesic end point). Kin 32.8 mg/dL/day (= 1.37 mg/dL/h derived)
is close to Kim 2011's simvastatin value 1.14 mg/dL/h (p8/printed 831 text).

## Covariates
Ezetimibe co-administration: additive +0.109 to INH (Kin down 10.9%) — the only
significant co-medication (fenofibrate, bezafibrate, tocopherol nicotinate not
significant). Age on baseline: Baseline = 152·(age/62)^-0.240 (baseline LDL-C
falls with age). No weight/sex/BMI covariate retained.

## Caveats
Retrospective EMR data, no PK/compliance/diet/exercise data, no concentrations.
Very few patients at high doses and only 12 on rosuvastatin+ezetimibe (not a
crossover). ID50 shrinkage ~40%-55%, so individual potency is weakly identified.
Ezetimibe captured only as a covariate on Kin (all ezetimibe patients were on
rosuvastatin). Note internal inconsistency: discussion (printed 831) states median
age 68, whereas Table 1 medians are 61-64.
