# Stillemans 2021: darunavir external validation and optimal sampling

## Study
External validation of the authors' earlier darunavir (DRV) population PK model (Stillemans 2020, Clin Pharmacokinet; ref 1), followed by D-optimal sampling design. Learning set: 127 HIV patients, 405 samples (12 rich 6-h profiles after 800 mg q24h plus sparse random-time samples), mostly cobicistat-boosted (85.8%). Validation set: 164 patients, 180 plasma samples (one per dose interval, random post-dose times), all ritonavir-boosted; 800 mg q24h in 67.1%, 600 mg q12h in 29.3% (p. 610 Table 1). Plasma DRV by LC with diode array detection. NONMEM 7.4.3, PsN 4.7.0, PopED 0.4.0 for D-optimal design. AAG was not measured in the validation set, so the validated model was the final model with AAG removed (OFV rose 43 points). 51 patients are in both sets.

## Model and parameters
One-compartment model, first-order absorption and elimination, with covariates AAG, sex, CYP3A5*3, SLCO3A1 rs8027174 (p. 608). Table 2 (PDF p. 8, printed 614; read from the page image): learning-set estimates, then the merged learning+validation refit, then bootstrap median [95% CI]. Values are apparent (CL/F, V/F); body weight is not a covariate and no per-kg scaling is used.

Validation results: with parameters fixed, two concentrations (13.6 and 14.01 mg/L) were badly underpredicted; NPDE departed from normality (Wilcoxon p 0.1, variance p 0.39, Shapiro-Wilk p 0.01, global adjusted p 0.04). Parameters were stable on refit to the merged set (p. 611-613).

## Pharmacodynamics and end points
None. No PD, MEAC, ke0 or potency data. DRV is an antiretroviral protease inhibitor; the authors note that no exposure-efficacy link has been convincingly shown (p. 614). Trough (C0) "recommended levels" are mentioned but no value is stated.

## Covariates
AAG (removed for validation), sex, CYP3A5*3, SLCO3A1 (Table 2). Race, weight, boosting agent and concomitant drugs were not model covariates; boosted by cobicistat or ritonavir (the model was built mostly on cobicistat data and validated on ritonavir data).

## Caveats
Validation set sparse, one sample per interval, few absorption-phase samples (ka poorly estimated, wide CI); AAG missing; genotype missing in 11% and imputed with the most frequent genotype. The sampling designs were evaluated by simulation on the learning set, not on observed validation data. Optimal designs assumed steady state at 800 mg q24h.

Optimal sampling (D-optimal, PopED; Table 3, PDF p. 8, simulated AUC0-24 accuracy, rho / MPE % / RMSPE % / % of AUCs within 15%):
