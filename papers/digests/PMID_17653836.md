# Savic 2007: the transit-compartment (gamma-input) absorption model vs the lag model

## Study
Methods paper. Compares a lag-time model (LAG) with an analytical transit-compartment model (TRANSIT, non-integer
number of compartments n estimated) on four oral data sets in NONMEM VI beta (FOCE INTER): glibenclamide (8
healthy volunteers, IV and PO, 18 samples each), furosemide (43 heart-failure patients, 3-4 samples), moxonidine
(74 heart-failure patients, 6-8 samples), amiloride (43 patients, 3 samples) (Table 1). Zolpidem is not studied;
stanpumpR cites the paper for the transit formula.

## Model and parameters
Chain of n transit compartments with common rate ktr, then an absorption compartment emptied at ka into central.
- Amount in the nth transit compartment (Eq. 2): a_n(t) = F x Dose x (ktr t)^n e^(-ktr t) / n!.
- Input to the absorption compartment (Eq. 4): Dose x F x ktr x (ktr t)^n e^(-ktr t) / n! - ka x Aa, with n!
  replaced by Stirling's approximation sqrt(2 pi) n^(n+0.5) e^(-n) (error < 1% for n > 2) and a log transform
  (Eq. 5) for large n.
- ktr = (n + 1) / MTT (Eq. 6); MTT is the mean time to reach the absorption compartment.
- As n goes to infinity at fixed MTT the TRANSIT input approaches the LAG model (Fig. 3).
- The input is a gamma density (non-integer n); Erlang when n is an integer (Discussion).
- Limitation: requires the whole dose at time 0; not for continuous input into the chain.
Estimated n: glibenclamide 22.9, furosemide 20.1, amiloride 8.15, moxonidine 7.17 in Results text (Table 4 shows
8.17). TRANSIT lowered OFV for all four (up to -483). Example (Table 2, glibenclamide): LAG ka 0.51 /h, tlag 0.306 h;
TRANSIT ka 0.65 /h, MTT 0.458 h, n 22.9.
