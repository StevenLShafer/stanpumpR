# Liu 2013: closed-loop propofol-remifentanil (BIS) in rigid bronchoscopy

## Study
Single-centre (Hopital Foch) randomized trial, Feb-Jun 2008; 70 randomized, 67 analysed (manual TCI n=34, dual-loop n=33; PDF p4). Adults 18-90 y for rigid bronchoscopy; >half ASA III-IV. Median [IQR] (Table 1, PDF p4): age 59 [49-71] vs 65 [57-73] y; weight 67 [55-81] vs 69 [56-77] kg; height 166 cm both; M/F 23/11 vs 18/16.
Both arms: TCI with Infusion Toolbox 95, propofol by Schnider 1999 and remifentanil by Minto 1997 (inputs sex, weight, height listed for the controller). Goal BIS 40-60 (controller set point 50). Same controller as Liu 2011 (Anesth Analg 112:546). Controller rules stated (PDF p3): minimal interval between consecutive control actions equals the **time to peak effect of each drug** (shorter for remifentanil, so it changes more often); default maintenance Ce limits propofol 1.3-5 ug/mL, remifentanil 3-12 ng/mL. Mivacurium for relaxation; high-frequency jet ventilation. Primary outcome % of maintenance time with BIS 40-60.

## Model and parameters
No PK model fitted; Schnider and Minto used as published. No parameter table.

Results (median [IQR], confirmed on page images):
- Table 2 (PDF p5): BIS 40-60 69 [48-79] vs 70 [58-80] % (P=0.81); BIS<40 25 [13-36] vs 23 [13-32]; BIS>60 5 [2-12] vs 7 [2-10]; MDAPE 15.8 vs 16.1; wobble 9.0 vs 9.5; Global Score 37 [26-76] vs 34 [25-49] (P=0.65).
- Table 3 induction (PDF p6): duration 261 vs 236 s; propofol 1.5 [1.1-2.1] vs 1.0 [0.7-1.4] mg/kg (P=0.002); remifentanil 2.0 [1.5-3.1] vs 1.8 [1.4-2.8] ug/kg; mivacurium 0.14 mg/kg both.
- Table 4 maintenance (PDF p6): duration 32 min both; propofol 4.7 [2.8-6.8] vs 4.9 [4.1-6.3] mg/kg/h; remifentanil 0.13 vs 0.16 [0.13-0.26] ug/kg/min (manual IQR printed "0.07-18", evidently a missing "0." or decimal; as printed); target changes/h propofol 7 vs 20, remifentanil 4 vs 20.
- No overrides needed in the dual-loop arm; no awareness.

## Pharmacodynamics and end points
- End point: BIS (EEG). Adequate depth BIS 40-60.
- No ke0, t1/2 ke0, tPeak value, EC50, MEAC or analgesic concentration is reported. tPeak is mentioned only as the controller's minimum interval (PDF p3), without numbers; no effect-site concentration medians are given in this paper.
- No equianalgesic or potency ratio.

## Covariates
None analysed.

## Caveats
- Underpowered for equivalence; authors say superiority could not be established. Short maintenance (32 min median); jet ventilation and neuromuscular-block artefacts may disturb BIS; Hawthorne effect ("man-machine challenge") favours the manual arm.
- Dual-loop performance was worse than in the authors' earlier routine-surgery study (BIS 40-60 82% there).
- Basis of mg/kg and ug/kg/min (actual weight?) not stated.
