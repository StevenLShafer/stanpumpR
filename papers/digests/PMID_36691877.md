# O'Hanlon 2023: fat-free mass, creatinine production and normal GFR from neonates to adults

## Study
Modelling paper with three submodels, NONMEM 7.5.1 (FOCE-I), 100-replicate nonparametric bootstrap, VPCs:
1. Fractional fat-free mass (FRFFM) relative to the adult Janmahasatian 2005 prediction: 15 studies, 4462 subjects,
   100 mean FFM values + 2747 individual FFM observations (text says 2847 in the abstract), PMA 95th-percentile
   interval 40.6-1134 weeks.
2. Creatinine production rate (CPR): 108 subjects from Rhodin 2009 with GFR (not BSA-indexed) and SCr, PMA
   27.8-872 weeks. Jaffe SCr converted to enzymatic equivalent with FScr = (88.4 - 22.25)/88.4 = 0.748 (Eq. 12).
3. Normal GFR (nGFR): Rhodin 2009 data, 1153 GFR observations in 923 subjects without kidney disease, PMA 28.3-1071
   weeks, refitted with FFM-based size and a postnatal-age birth effect.
Renal function RF = eGFR / nGFR, with eGFR = CPR / SCr (Eqs. 22-23). Evaluated on 9998 patients (GAVamycin database).

## Model and parameters
Size: NFM = FFM + Ffat x (TBM - FFM) (Eq. 2); NFMstd = 56.1 + Ffat x (70 - 56.1) for a 70 kg, 1.76 m male
(Eq. 3); Fsize = (NFM/NFMstd)^WBE (Eq. 4), exponent 1 for structure, 3/4 for function.

FRFFM = FFMIN + FFNEO + FFKID (Eqs. 6-9): baseline, exponential neonatal component falling from FMAT_PRE (24-week
premature neonate) with half-life TFF_PRE, and an asymmetric sigmoid child component with A50, HILL_Y, HILL_O; all
sex-specific; capped at 1.16 (males) and 1.19 (females). Table 1 values are not reliably assignable to rows from the
text layer (column layout scrambled) and are not transcribed here.

CPR = CPRstd x Fsize x Fmat,CPR (Eq. 13), CPRstd 0.386 mmol/h/70 kg (= 0.516 x FScr; enzymatic, 40-year-old male),
size by FFM (Ffat 0, exponent 1). Maturation: constant CPRint at PMA <= 37 weeks (Eq. 14); linear
1 + CPRslope x (PMAadult - PMA)/100 from 37 to 1080 weeks (Eq. 15); adults > 20 y PNA: (112 - AGE)/(112 - 40),
x 0.82 if female (Eq. 16, Matthews modification of Cockcroft-Gault); low-SCr variant (119 - AGE)/(119 - 40) x 0.7
(Eq. 17).

nGFR = GFRstd x Fsize x Fmat,PMA x Fmat,PNA (Eq. 19); Fmat,PMA = 1/(1 + (PMA/PMAT50)^-HILL) (Eq. 20);
Fmat,PNA = 1 - PNAmax + PNAmax x (1 - exp(-ln2 x PNA/PNAT50)) (Eq. 21).

## Pharmacodynamics and end points
Not applicable (no drug).

## Covariates
Total body mass, height, sex, postmenstrual age (weeks or years), postnatal age (days), serum creatinine.
Non-steady-state creatinine kinetics handled by Eq. 18 (Vcr 0.5 L/kg).

## Caveats
- Requires postmenstrual age and postnatal age; source data for CPR are Jaffe SCr corrected by a single average factor.
- High uncertainty in female A50 (sparse data 1.5-4 y PMA).
- Standard male FFM 56.1 kg at 70 kg / 1.76 m (not the 54.5 kg reference man that stanpumpR uses; different height).
- A corrigendum exists (2024;13:181-2) and is not part of this PDF; its content is not checked here.
