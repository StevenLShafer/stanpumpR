# Nath 2010: total and unbound melphalan in myeloma, high-dose therapy

## Study
Prospective, multicentre, observational (six Sydney hospitals; ACTRN0126000231549). 100 adults with multiple myeloma
(59 male, 41 female) before autologous stem-cell transplant. Table 2 (PDF p4, printed p487), median (range): dose
368 (150-450) mg, 192 (115-216) mg/m2; age 57 (36-73) y; weight 78 (42-132) kg; height 168 (147-185) cm; BSA 1.9
(1.3-2.6) m2 (Mosteller); BMI 27.6 (19.2-40.9); FFM 53.3 (34.4-80.5) kg (Janmahasatian); CLcr 97 (29-234) mL/min and
88 (26-205) mL/min/70 kg (Cockcroft-Gault, total weight); haematocrit 34 (20-45)%; albumin 37 (14-49) g/L; total
protein 71 (39-117) g/L. 37% had BMI > 30.

Melphalan (Alkeran) IV over a median 35 min (15-95). Sampling: 63 patients at end of infusion, 5, 10, 20, 30, 40,
50 min, 1, 2, 3, 4, 8 h after; 37 patients 5-6 samples in D-optimal windows (Table 1, POPT). Plasma, HPLC-UV
(methanol precipitation for total, ultrafiltration for unbound); detection limits 0.1 ug/mL total, 0.05 ug/mL
unbound (the text layer renders the micro sign as "m"; Table 8 prints ug/mL). 1057 total and 691 unbound
concentrations. NONMEM 6, FOCE with interaction; bootstrap 1000 runs.

Cockcroft-Gault as printed (PDF p3/printed p485): CLcr (mL/min) = (140 - age) x TBW / (creatinine umol/L x 0.814),
x 0.85 if female; normalised to 70 kg by dividing by TBW and multiplying by 70. Creatinine enzymatic, IDMS-aligned.
FFM (Janmahasatian): male 9.27e3 x TBW / (6.68e3 + 216 x BMI); female 9.27e3 x TBW / (8.78e3 + 244 x BMI).

## Model and parameters
Two compartments, first-order elimination, exponential IIV, combined proportional + additive residual error.

Base model (Table 3, PDF p6/printed p489), population mean (IIV %CV): total CL 27.8 L/h (33.6), V1 13.1 L (59.5),
Q 31.3 L/h (42.4), V2 15.1 L (34.4); unbound CL 128 L/h (41.7), V1 60.1 L (57.2), Q 160 L/h (45.8), V2 72 L (33.6).

Final model (Table 5, PDF p8/printed p491, CLcr in mL/min/70 kg; the authors' preferred model):

CL = CLNR + CLR; CLNR = th1 x (HCT/34)^th2 x (FFM/50)^0.75; CLR = th3 x (CLcr/88); V1 = th4 x (FFM/50); Q = th5; V2 = th6.

## Pharmacodynamics and end points
No effect site, no ke0, no concentration target (not an opioid; no MEAC, potency ratio or tPeak). Exposure-toxicity
only (Table 9, PDF p11/printed p494, median AUC, Mann-Whitney): clinical oral mucositis grade 3-4 vs 0-2, total AUC
16.9 vs 13.4 mg h/L (P < 0.05), unbound 4.4 vs 2.8 (P < 0.001); hospital stay >= 21 vs < 21 days, total 16.3 vs
13.3 (P < 0.01), unbound 3.9 vs 2.9 (P < 0.01); vomiting grade 2-3, unbound only (3.8 vs 2.7, P < 0.05). Overall
response CR/VGPR vs others, unbound AUC 3.2 vs 2.8 (P < 0.05); melphalan-related response, total AUC 21.3 vs 13.4
(P = 0.062, n = 7 responders). No therapeutic range is proposed.

## Covariates
Screened (Table 4): CLcr (both units), HCT, TBW, FFM, BSA, age, sex, albumin, total protein. Retained: CLcr on
renal CL; HCT (power) and FFM (allometric 0.75) on non-renal CL; FFM (linear) on V1. Age, sex, albumin, protein,
paraprotein, transferrin, IgA vs IgG not retained. Note the Table 4 FFM reference is 53, the final 50.

## Caveats
Total and unbound modelled separately (no joint binding model). Sampling to 8 h at most. HCT effect novel and
imprecise (th2 95% CI 0.060-0.954). Dataset described as incomplete/ongoing. Response analysis underpowered.
FFM reference inconsistency (see open question). Unit of the additive residual SD is not printed.
