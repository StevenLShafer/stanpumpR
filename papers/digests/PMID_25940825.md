# Al-Sallami 2015: fat-free mass prediction in children (maturation model)

## Study
Dunedin, New Zealand (Otago Mineral Metabolism Group). FFM measured by DXA (Lunar DPX-L). Index dataset (2000-2005):
496 females (926 observations) and 515 males (853 observations), age 3-29.7 yr, weight 12.3-120.1 kg, BMI 12.6-41.3
(Tables 1-2); test dataset (2006-2009): 90 females, 86 males, one observation each. Mostly Caucasian. Three models:
M1 fully empirical mixed linear regression (STATA), M2 maturation model (NONMEM 7.2), M3 the published adult model of
Janmahasatian 2005 applied directly.

## Model and parameters
M3 (adult, Janmahasatian; Eqs. 1a-1b; WT kg, BMI kg/m²):
male FFM = 9270·WT/(6680 + 216·BMI); female FFM = 9270·WT/(8780 + 244·BMI).
M2 (final; Eq. 5, sigmoid hyperbolic in postnatal age, asymptote b = 1 fixed, so adult value = M3):
FFM = [a + (b − a)/(1 + (Age/A50)^−γ)] × M3 (Eqs. 6a-6b, reconstructed with Table 4).

Performance (Table 5, bootstrap mean (95% CI)): index ME M1 0.09, M2 0.24, M3 0.29 kg; RMSE 1.12, 1.58, 3.76 kg.
Test ME M1 −0.16, M2 −0.56, M3 −1.49 kg; RMSE 1.14, 2.02, 4.32 kg. Female test ME: M3 0.21 vs M2 −0.25 kg; male test
ME: M3 −3.24 vs M2 −0.77 kg (p. 1175). M1 (Eq. 4, nine terms incl. Tanner score and bone mineral content) is not for
clinical use.

## Pharmacodynamics and end points
Not applicable (body-composition model). No PK parameters, no MEAC, ke0 or potency ratio.

## Covariates
Age (postnatal, years), sex, weight, BMI (height). Authors state M2 can be used to predict FFM from 3 to 70 years;
not to be extrapolated below 3 years (no subjects < 3). For females the adult model performs similarly to M2.

## Caveats
No subjects under 3 years; Caucasian-majority population; DXA as reference; unbalanced repeated measures (BSV hard to
estimate). The paper is about FFM only: it does not supply any exponent for scaling clearance (its Key Points say FFM
correlates linearly with clearance in adults); the 0.75 exponent stanpumpR applies to clearance comes from allometric
theory, not from this paper.
