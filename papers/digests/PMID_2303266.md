# Jacobs 1990: optimal linear model-based control for model-driven infusion

## Study
Communication (Duke, Anesthesiology and Biomedical Engineering); received Sept 1988, revised March 1989; supported in part by Abbott Laboratories. No patient data. Describes the pump-control algorithm used in the Duke CACI device for fentanyl, sufentanil, alfentanil, propofol and midazolam (refs 10, 14, 15).

## Model and parameters
Generic linear PK model, no drug parameters. Control loop (Fig. 1): the clinician sets a setpoint Cp_d; at intervals dt (typically 10-30 s) the simulated Cp is compared with it and a rate is computed.

Rate algorithm (Fig. 2, p. 107):
1. Simulate the plasma level at the end of the next interval for a trial rate x1 (Cp_x1).
2. Repeat for a second rate x2 (Cp_x2), x1 != x2.
3. Slope = (Cp_x2 - Cp_x1)/(x2 - x1); intercept = Cp at rate 0.
4. k0 = (Cp_d - intercept)/slope; if k0 < 0, k0 = 0.

By linearity this gives the rate that puts the model plasma concentration as close to the setpoint as possible by the end of dt (Discussion), i.e. exactly on it when unconstrained. Fig. 3 / text: convert to pump units (e.g. mL/h), truncate to pump resolution, clamp to the pump's min/max rates; feed the rate the pump **reports** back into the simulation, so occlusions and pauses are compensated. All simulation state variables must be available to the controller.

## Caveats
Optimal only with respect to the chosen sampling interval; intervals much below 10 s judged impractical for pumps. Suggests analytical equations (Jacobs 1988) rather than discrete approximations would improve it slightly. Claims advantages over earlier schemes: no assumption of instant boluses, accounts for pump resolution and reported pump behaviour, no empirical proportional control, setpoint changeable at any time.
