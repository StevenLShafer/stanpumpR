# Kim JR 2008: joint population PK of aripiprazole and dehydroaripiprazole with CYP2D6 genotype

## Study
- Multicentre phase IV study, 30 Korean sites (samples from 15 sites); schizophrenia, schizophreniform or
  schizoaffective disorder. CYP inducers/inhibitors excluded.
- n = 80 Korean patients, 46 female (57.5%) (Table 1, layout reassembled); age 35.2 +/- 9.8 (17-61); weight
  60.8 +/- 10.9 kg, median 61.9 (38.0-95.0); dose 24.3 +/- 6.7 mg/day, median 27.5 (10-30).
- Dosing: 15 mg/day for several days, titrated 5-45 mg/day, sampled at steady state; 141 samples (1-2 per
  patient), mostly trough and/or about 6 h post dose.
- Concentrations (Table 1): aripiprazole 445.6 +/- 220.9 ng/mL, median 413 (55.5-1442); dehydroaripiprazole
  129.3 +/- 60.4, median 120 (31.7-428).
- Assay: LC-MS/MS, plasma, LLOQ 0.1 ng/mL for both analytes.
- Genotypes (Table 2; text): CYP2D6 Group I two functional alleles (n = 15), II functional + partially deficient
  (26), III functional + null (12), IV IM = no functional allele, at least one partially deficient (27). No
  multiplication carriers, no PMs. EM defined as >= 1 functional allele (Groups I-III). CYP3A5 expressers 36,
  non-expressers 44.
- NONMEM VI, ADVAN6, FOCE-I.

## Model and parameters
One compartment for parent and one for metabolite, first-order absorption, no lag. Parent converted to metabolite
only from the parent central compartment: dA(m)/dt = fm x (CL/V) x A(p) - (CLm/Vm) x A(m). fm not identifiable:
fitted with fm = 1, so metabolite estimates are CLm/fm and Vm/fm. Mass units (MW treated as equal). ka fixed at
1.06 /h from a previous population analysis (ref 20). IIV on CL/F, V/F, CLm/fm; covariance CL/F-CLm/fm;
proportional error. Table 3 (estimate (SE); CV% = sqrt(omega2)):

Half-lives (Results, base model): aripiprazole 56.2 h, dehydroaripiprazole 83.4 h. Derived final-model metabolite
t1/2 = 0.693 x 587 / 8.02 = 50.7 h. Metabolic ratio MR = F x (CL/F) / (CLm/fm) with F = 0.87 from the label
(Methods equations): 0.26 base; 0.34, 0.29, 0.25, 0.20 in Groups I-IV (calculated, not observed AUC ratios;
derived check 0.87 x 3.15 / 8.02 = 0.342, 0.87 x 1.83 / 8.02 = 0.199). Group IV CL/F about 60% of Group I
(1.83/3.15 = 0.58, derived). Merging Groups I-III worsened OFV by 15.8. CYP2D6 on CL/F: dOFV -63.4.

## Pharmacodynamics and end points
None fitted. Discussion quotes D2/D3 saturation above 100-150 ng/mL (patients, Gründer 2008) and 100-200 ng/mL
(healthy), and best response at 150-300 ng/mL; median concentration here 413 ng/mL (594 in IMs). Not an opioid;
no MEAC, ke0 or potency ratio.

## Covariates
CYP2D6 genotype group on CL/F (four categorical values). Age, weight, sex and CYP3A5 not significant (weight range
narrow, CV 18%). Continuous covariates were tested linearly, centred at medians.

## Caveats
Sparse (1-2 samples per patient), ka fixed, no lag, one compartment (early post-dose concentrations underpredicted,
authors), presystemic metabolite formation ignored, Vm/fm imprecise and shifted between base and final models,
Korean patients only, no PMs/UMs, reference weight about 61 kg (not 70). The paper's MR formula multiplies by
F = 0.87 although F is never separately identified in the fit.

## Verification against stanpumpR
- **V/F: discrepancy (small).** R/drugs_aripiprazole.R:14-15, 26, 67 and help aripiprazole.md:3, 5 use 192 L "from
  the abstract" and treat the brief's 193 L as doubtful. Table 3: 192 L is the BASE model (CL/F 2.37 without
  genotype); the FINAL model, whose genotype clearances (3.15/2.66/2.27/1.83) and metabolite values (8.02, 587) the
  code uses, has V/F 193 L. The brief was right; 193 L is the consistent value (0.5% difference, clinically
  negligible). Test pin tests/testthat/test-drugs-aripiprazole.R:~12 (v1 = 192) would move with it.
- Genotype CL/F 3.15, 2.66, 2.27, 1.83 L/h (aripiprazole.R:27-29, 71-76; help :9): Table 3 final. **matches**
  (the "NOT checked" notes at aripiprazole.R:10-12, dehydroaripiprazole.R:10-11, help, R/antipsychotics.R:118-122
  and docs/antipsychotics.md:43 can be cleared).
- CLm/fm 8.02 L/h, Vm/fm 587 L, t1/2 51 h (dehydroaripiprazole.R:7, 19-20): Table 3 final; derived 50.7 h.
  **matches**. Note the base model gave Vm/fm 950 L (t1/2 83 h, the paper's quoted half-life); authors call 587 L
  imprecise (SE 217 L).
- ka 1.06 /h fixed, no lag, one compartment each: **matches**.
- Formation convention (aripiprazole.R:39-50, "assumed, not read from the paper"): the paper's equations state
  exactly this: metabolite formed at fm x (CL/V) x A(p) with fm = 1 and metabolite parameters reported as /fm.
  **matches**; the convention is the paper's, not an assumption.
- Metabolite-to-parent ratio (aripiprazole.R:47-48; help dehydroaripiprazole.md:7; test :67): the repo says 0.39 and
  0.23 "against 0.20 to 0.34 observed". The 0.20-0.34 are not observed: they are the paper's calculated MR,
  F x (CL/F)/(CLm/fm) with F = 0.87, and 0.87 x 0.39 = 0.34, 0.87 x 0.23 = 0.20 exactly. The repo's model
  reproduces the fitted model; the wording should change (**discrepancy in description, not in values**).
- CYP2D6 mapping (aripiprazole.R:34-37): "normal" = Group I only (two functional alleles, n = 15). The paper
  classes Groups I-III (n = 53) as EMs; under a CPIC activity-score reading Groups II (*1/*10, AS 1.25) are normal
  and III (*1/null, AS 1) intermediate. Using 3.15 for every normal metaboliser is the highest-clearance choice;
  a judgment the header should state. **cannot verify** as right or wrong; flag.
- Body size (aripiprazole.R:52-53): repo treats values as a 70 kg reference; the paper's population median weight
  was 61.9 kg and weight was not a covariate. Repo convention (docs/weight-adjustment.md), noted only.
- Population description "80 patients on 10 to 30 mg/day", 141 samples, plasma: **matches**.
