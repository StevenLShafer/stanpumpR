# Hemmerling 2013: McSleepy closed-loop TIVA vs manual TIVA

## Study
Single-centre (McGill, Montreal) randomized controlled trial, 186 adults (>=18 yr, elective surgery >=60 min) randomized in blocks of five, 93 per group analysed (Fig 1: removals for system error, communication error or corrupted data file). Age about 57 (15) vs 56 (15) yr, weight about 75 (13) vs 80 (15) kg (Table 1, scrambled in text layer). Anaesthesia duration 195 (86) vs 191 (95) min.
Closed-loop group: propofol controlled on BIS target 45; remifentanil controlled on Analgoscore (HR and MAP offset score, -9 to +9) target 0; rocuronium 0.2 mg/kg bolus when TOF ratio >25%. Control group: manual TIVA with the same drugs and targets. Propofol dose rule: previous dose x Km x Kh; remifentanil: previous dose x Kr x Ksr (no coefficient values given). Primary outcome: time within 10% / 11-20% / 21-30% / >30% of BIS 45; secondary: Varvel indices (MDPE, MDAPE, wobble, divergence, GPI).
Induction algorithm (Fig 3): remifentanil 0.5 ug/kg/min for 2 min, 0.2 for the third minute, then 0.1; propofol starts at 2 min, 1.5-2 mg/kg depending on ASA/age, extra 0.5 mg/kg if BIS not <60 after 60 s; rocuronium 0.6 mg/kg when BIS <60. Fentanyl 100-150 ug given 15 min before end of surgery.

## Model and parameters
No pharmacokinetic model; the controller is rule-based and no PK parameters are reported.
```yaml
parameters: []   # no PK parameters; controller performance only
```
Selected results (abstract and text): excellent hypnosis control 47.0 (9.8)% vs 37.3 (14.3)% of time; good 34.4 (4.7)% vs 32.3 (7.6)%; excellent analgesia control 78.7 (16.2)% vs 73.7 (17.8)%. BIS MDPE -5.9 (4.3)% vs -10.8 (11.9)%; MDAPE 11.0 (2.6)% vs 15.4 (10.4)% (Table 2). Extubation time 10.1 (4.7) vs 13.7 (8.8) min (Table 3). Total rocuronium 1.1 mg/kg both groups.

## Pharmacodynamics and end points
Opioid audit (remifentanil): no MEAC / analgesic concentration, no ke0 / t1/2ke0 / tPeak / hysteresis, no equianalgesic or potency ratio reported. No concentrations measured or modelled. The analgesia end point is the Analgoscore (haemodynamic, not a concentration end point). BIS target 45 for propofol; no EC50 or ke0.

## Covariates
Sex, age, ASA, weight, height and surgery type are inputs to the system; no covariate equations given.

## Caveats
Not double-blind; possible Hawthorne effect in the manual group; BIS is an indirect measure of hypnosis; no validated intraoperative pain measure; many patients removed from analysis for technical reasons. The first author holds the McSleepy patent.
