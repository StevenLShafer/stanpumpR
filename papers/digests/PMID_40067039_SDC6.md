# Vellinga 2025 SDC6: PD model development (BIS, MOAAS, TOL, TOTS)

## Study
- Supplement to the Anesthesiology paper (trial design in PMID_40067039.md). Observations: 891 BIS, 1025 MOAAS, 374 tolerance-to-laryngoscopy (TOL), 611 tolerance-to-tetanic-stimulus (TOTS), over three sessions (PDF pp. 1, 10, 21, 29).
- NONMEM 7.5 with ADVAN6. PD is driven by the individual PK parameters from SDC5 (read in as data items IV1...IQ3R: remimazolam V1-V3, CL, Q2, Q3; CNS7054 CLM, V5, KTR; remifentanil Eleveld parameters; IC50 and gamma of the remifentanil effect on CNS7054 clearance). The PD code rebuilds the full 8-compartment PK in the DES block (PDF pp. 4-8). Fraction metabolised 0.8. Concentrations: CP remimazolam ng/mL (plasma), CM CNS7054 ng/mL (scaled by 425.3/439.3), CR remifentanil ng/mL.
- Estimation: FOCE-I for BIS; Laplacian (likelihood, numerical) for MOAAS, TOL, TOTS. All models evaluated against plasma concentrations from the PK model, not effect-site concentrations: no ke0 appears in any of the PD code.

## Model and parameters
Model building as reported (delta OFV from the text; df and p as printed):
- **BIS (PDF p. 1)**: the period-1 model refitted to all periods. A remifentanil interaction on drug effect (equation 2) improved fit (delta OFV -8.9, df 1, p=0.002); its EC50 was 32.3 ng/mL, far above the observed maximum remifentanil, so it was removed at that stage. Removing competitive antagonism by CNS7054 worsened fit (+285.6). IIV on Emax and a combined additive plus proportional logit-scale error improved fit (-107.0, df 2). Re-testing remifentanil as an additive effect on drug effect (equation 6) improved fit (-26.3, df 1, p<0.001); removing CNS7054 antagonism again worsened it (+325.3).
- **MOAAS (PDF p. 10)**: proportional-odds ordinal model. Remifentanil interaction (equation 2) improved fit (-171.6, df 2); removing CNS7054 antagonism worsened it (+328.4). Moving IIV from Emax to the baseline parameters improved fit (-29.8, df 0).
- **TOL (PDF p. 21)**: logistic model. A remimazolam effect alone did not improve fit (-0.3, p=0.58). Remimazolam plus remifentanil interaction on the remimazolam C50 improved it (-83.1, df 2). CNS7054 competitive inhibition not supported (-1.4, p=0.24). IIV moved from baseline to C50 remimazolam (-22.2, df 0). Baseline probability of tolerance not different from 0 at 5%, so fixed at 0.
- **TOTS (PDF p. 29)**: remimazolam effect improved fit (-55.5, df 1); remifentanil on remimazolam C50 improved it (-134.2, df 1); CNS7054 inhibition not supported (-1.5, p=0.22); IIV moved to C50 (-26.5); baseline fixed at 0.

Structural forms in the code (rendered from the text layer; PDF pp. 6-8, 16-19, 26-27, 33-36):
- BIS: logit(BIS/100) = LBASE - DRUGB; DRUGB = EMAXB * (CA + CC)/(1 + CA + CB + CC), with CA = CP/EC50B, CB = CM/EC50MB, CC = CR/EC50RB (additive remifentanil term). BASEB, EMAXB, EC50B, EC50MB, EC50RB are exp(THETA) (EC50RB is THETA(7)).
- MOAAS: DRUGM = EMAXM * CAM/(1 + CAM + CBM) * (1 + CCM), CAM = (CP/EC50M)^GAMMAM, CBM = CM/EC50MM, CCM = CR/EC50MR; the five cumulative logits LLE0-LLE4 shift by DRUGM + ETA_BASE; cumulative probabilities by expit. Remifentanil acts multiplicatively on the drug effect.
- TOL and TOTS: CA = CP/(EC50T*(1 - CR/(CR + EC50TR))); DRUGT = CA/(1 + CA + CB) with CB set to 0 (no CNS7054 term); probability of tolerance = DRUGT (baseline 0). Remifentanil lowers the remimazolam C50 by up to the full amount as CR grows (a saturating factor 1 - CR/(CR + EC50TR)).

## Pharmacodynamics and end points
- End points: BIS (logit scale), MOAAS (ordinal, 0-5), TOL, TOTS (binary). All against plasma concentrations; **no ke0, t1/2ke0, tPeak or hysteresis analysis is in this supplement**. Acute tolerance to remimazolam is modelled as competitive antagonism by the metabolite CNS7054 (supported for BIS and MOAAS, not for TOL or TOTS).
- Remifentanil: only an interaction on remimazolam effect (additive for BIS, multiplicative for MOAAS, reduction of C50 for TOL and TOTS). The first BIS interaction EC50 was 32.3 ng/mL (PDF p. 1). **No MEAC or analgesic concentration, no equianalgesic ratio, no remifentanil effect-site data** are reported.
- Opioid audit: remifentanil values here are interaction parameters on remimazolam effect, not analgesic end points: none to record.

## Covariates
- None on the PD parameters. IIV on BIS baseline and Emax (BIS), on baseline (MOAAS), on C50 remimazolam (TOL, TOTS). Remifentanil concentration enters all four models.

## Caveats
- Starting-value code only; final estimates and CIs are in the main paper. No stanpumpR-relevant number is read from this file.
- TOL and TOTS baseline fixed at 0% tolerance; remifentanil exposures low (see main digest).
- The sign/form of the MOAAS interaction, (1 + CCM), means remifentanil effect has no ceiling in that equation; the main paper's equation 2 was not checked against it here.
