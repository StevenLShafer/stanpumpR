## Study
No new study. The supplement adds to the parent article (card `PMID_30259707.md`, pooled 12-study NONMEM analysis):
visual predictive checks (observed geometric mean, 90% prediction interval), the stage 1 parameter estimates (Table
S1), the final-model equations (Table S2) and predicted 2.5 mg BID exposures in the dose-reduction subgroups (Table
S3).

## Pharmacodynamics and end points
None. Total plasma apixaban only; no anti-Xa, no ke0, no exposure-response.

## Covariates
As Table S2 above (cCrCL on CLR/F; age and sex on CLNR/F; race, AF, ACS, inhibitor on total CL/F; weight, AF, ACS on
Vc/F; evening dosing on ka; dose on Frel). Stage 1 (Table S1) also tested weight on CLNR/F, Black and Other race,
and dosing time on CL/F, all dropped from the final stage 1 model.

## Caveats
- **The supplement's equations are not the code that was fitted.** Equation [1b] has no cap, but all four companion
  control streams cap cCrCL at 150 mL/min (`IF(D_CCRCLB.GE.150) FLG=1`, `CRCL=(1-FLG)*D_CCRCLB+FLG*150`) before
  `TVCLR`, and the main article's Eq. 1 (PDF p. 2) defines the same FLAG. sup0004/0005 (`finalmodel_japan-korea_2014`,
  the model Table S2 writes out) use `(CRCL/80)**THETA(7)`; sup0002/0003 (stage 1, `finalmodel1`) use `CRCL/70` and
  also normalise weight to 65 kg and age to 69 y. So Table S2 [1b] omits a truncation the fitted model applies, and
  Table S1 does not state its stage 1 reference values (70 mL/min, 65 kg, 69 y are from the control streams, not this
  PDF).
- Table S1 labels the weight and age effects as slopes ("[(L/hr)/kg]", "[(L/hr)/yr]", "(L/kg)"), but the control
  streams apply them as power exponents; the unit labels are evidently wrong.
- Theta numbering differs between Table S1 (stage 1) and Table S2 (separate-Asian stage 2 model), e.g. evening-dose
  ka is theta13 in S1 and theta10 in S2; gamma is theta9 in S1 and theta8 in S2.
- Table S2's [1c] age exponent printed "14"; KOR undefined in the Note.
- No stage 2 parameter values appear in the supplement at all; the stage 2 numbers stanpumpR uses come from the main
  article's Table 3.

## Verification against stanpumpR
- **CrCL cap: discrepancy.** R/drugs_apixaban.R:55-62 is right about what the supplement PDF *prints*: Eq. [1b]
  (p. 8) has a single exponent theta7 with no FLAG, and Table S1 (p. 6) lists cCrCL on CLR/F as 1 FIXED with no
  breakpoint. But the PDF says nothing either way about a cap; it is silent, not a statement that there is none.
  The fitted model, as the companion control streams and the main article's Eq. 1 show, caps cCrCL at 150 mL/min
  before the renal term. The code (:125-128), help :20, test :32-48 and registry :4 therefore implement a model the
  authors did not fit; the difference is confined to cCrCL > 150 mL/min (above 150, code CLR/F keeps rising,
  fitted CLR/F holds at 1.57 x 150/80 = 2.94 L/h (derived)).
- **Reference CrCL 80 mL/min: matches** Eq. [1b] and the stage 2 control streams (code :128 `crcl / 80`). Stage 1
  used 70 (control stream; not in this PDF), irrelevant to the stage 2 code.
- **Frel, R/drugs_apixaban.R:73-76: matches** Eq. [1n] and [1l] in form. The values 0.857 and -0.322 are not in the
  supplement (main Table 3). Wording slip: the header says I50 is "the logit of theta9"; Eq. [1l] makes I50 the
  inverse logit (logit(I50) = theta9), as the code's `plogis(-0.322)` correctly computes.
- R/drugs_apixaban.R:56-57 cites "Table S1/S2" for the exponent: Table S1 is stage 1 (not the implemented stage 2)
  and Table S2 holds equations only; neither gives stage 2 numbers. Citation is loose, not wrong about the exponent.
- The parent card's note that "equation [1i] writes the renal term without the cap" mislabels the equation: the
  renal term is [1b]; [1i] is Vp/F = theta5 (p. 8). Recorded here, parent card not edited.
- Table S3 is not used by the repo (no 2.5 mg subgroup pins found); cannot verify, nothing to verify.
