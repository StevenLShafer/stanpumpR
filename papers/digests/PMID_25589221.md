# Tham 2015: erratum to Tham 2008 gemcitabine model (lean body mass equations)

## Study
One-page erratum (published online 15 January 2015) to Tham et al., Cancer Chemother Pharmacol
2008;63:55-64, doi 10.1007/s00280-008-0707-9 (archived as `PMID_18305939`). No data; it replaces Equations 1
and 3 of the original. The context file carries no PubMed metadata; the PMID is from the archive file name and
was not checked against PubMed.

## Model and parameters
Corrected equations, read on the rendered page (PDF p1):

- Eq. 1: LBM = LBMMAX x HT^2 x [WT / (WT50 x HT^2 + WT)]
- Eq. 3: LBMSTD = LBMMAX x 1.76^2 x [70 / (WT50 x 1.76^2 + 70)]

(The text layer drops the superscripts and prints "1.762"; the page image shows 1.76 squared.) The standard is
70 kg and 1.76 m. The erratum gives no values of LBMMAX or WT50 and no exponents.

```yaml
parameters: []  # erratum: equation forms only; no numeric parameters (standard WT 70 kg, HT 1.76 m)
```

## Pharmacodynamics and end points
None. Not an opioid paper.

## Covariates
Lean body mass (Eq. 1), normalised to the 70-kg, 1.76-m standard (Eq. 3).

## Caveats
- Constants LBMMAX and WT50 are not given here; the form is that of Janmahasatian 2005, but which (sex-specific)
  constants the original used is not stated in the erratum.

## Verification against stanpumpR
- `R/drugs_gemcitabine.R:31-33` prints LBM = LBMMAX x HT^2 x WT / (WT50 x HT^2 + WT): identical to the
  erratum's Eq. 1. **Matches.**
- `R/drugs_gemcitabine.R:79-84` normalises by `ffmAlSallami(70, 176, FFM_REFERENCE_AGE, SEX_MALE)`, i.e. a
  70-kg, 1.76-m standard, as Eq. 3 requires. `ffmAlSallami` (`R/pkSizeFactors.R:30-40`) computes
  9270 x WT / (6680 + 216 x BMI) for men, which rearranges to 42.92 x HT^2 x WT / (30.93 x HT^2 + WT) (derived),
  the erratum's form with Janmahasatian's male constants. At the standard this gives 56.13 kg (derived:
  42.92 x 3.0976 x 70 / (30.93 x 3.0976 + 70)), as the header line 39 says. **Matches** in form; the choice of
  constants and of male constants for the standard is the header's recorded decision (Shafer, 2026-11-06), which
  the erratum neither supports nor contradicts.
- This erratum settles the `[source]` open question in `papers/digests/PMID_18305939.md` (line 13), which asked for
  the erratum to confirm the corrected Eq. 1: it confirms the repo's form. That card is not edited here; it needs a
  `revised:` line closing the question.
