# Vos 2025: nortriptyline pharmacogenetic vs phenotype vs standard dosing

## Study
Secondary analysis of the Dutch PITA RCT. 48 of 101 nortriptyline-treated adults (18-65 y) with major depression had a concentration after the first dose (8-24 h) and at steady state (10-16 h post dose, after 1 week). Table 1 (PDF p4 image): 23 F (48%); age mean 42.0 (SD 13.8) y; CYP2D6 PM 5, IM 20, NM 21, UM 2. A population PK model (NONMEM 7.5) was built on 85 participants with at least one concentration; details only in ESM 1 (PDF p2). Three strategies were compared by modelled Css: DPWG genotype doses (PM 50, IM 75, NM 125, UM 200 mg/day), phenotype-based (empirical Bayes estimate from the single-dose sample, target Css 100 ug/L, linear PK), and standard 125 mg/day.

## Model and parameters
No parameter values in the main text. Structural statements only: linear PK; no structural bias in weighted residuals; the one earlier population model (Kvist 2001) was used to build theirs (PDF p6).
Table 2 (PDF p5, n=48), mean (SD), pharmacogenetic / phenotype / standard: target dose 99.5 (35.2) / 117.0 (42.3) / 125 mg/day; predicted Css 96.0 (32.6) / 111.2 (37.6) / 133.8 (59.3) ug/L. Therapeutic 42 (88%) / 40 (83%) / 30 (63%); sub 4 / 0 / 2; supra 2 / 8 / 16.

## Pharmacodynamics and end points
Therapeutic window 50-150 ug/L (RCT and Dutch SmPC); the consensus-guideline window 70-170 ug/L was used in a post hoc analysis (PDF p4-5; ESM 5). Assay and matrix are not detailed in the main text beyond "validated bioanalytical assay". No ke0 (not an opioid).

## Covariates
None reported in the main text; CYP2D6 is not in the PK model (the authors suggest adding it, PDF p6).

## Caveats
Simulation, not prospective; limited sampling; model needs external validation; RCT excluded interacting co-medication and comorbidity.
