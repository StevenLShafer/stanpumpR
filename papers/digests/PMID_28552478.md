# Holford 2017: theory-based allometry and normal fat mass

## Study
Review (University of Auckland). No new data apart from two "unpublished work" rows in Table 1. Argues for "theory based allometry" (West-Brown-Enquist): mass as the sole size variable, with fixed exponents **3/4 for functional properties (clearance, flows)** and **1 for structural properties (volumes, Vc, Vss)** (Sections 1, 3), as distinct from empirically estimated exponents.

## Model and parameters
- Eq. 1: Y = a x mass^beta.
- Linear per-kg dosing underpredicts adult-scaled CL by >10% below 47 kg and about 50% near 10 kg (Section 2, citing Holford 1996).
- Eq. 3 FFM (Janmahasatian 2005): FFM = WHSmax x HT^2 x TBM / (WHS50 x HT^2 + TBM); men WHSmax 42.92, WHS50 30.93; women 37.99, 35.98 (kg/m2). Al-Sallami 2015 extends it to children from 3 years.
- Eq. 4 **normal fat mass**: NFM = FFM + Ffat x (TBM - FFM); Ffat is drug- and parameter-specific (Ffat 0 means FFM alone, 1 means TBM).
- Eq. 5: allometric size = (NFM/NFMstd)^(3/4); NFMstd may use FFM 56.1 kg, a 70 kg, 1.76 m male.
- Eq. 7-8: child CL and dose rate = adult x (NFMchild/NFMadult)^(3/4).

Table 1 Ffat estimates (clearance / volume): GFR 0.22 / -; heparin 0 / 1; oxypurinol 0 / 0; gemcitabine 0 / 0; busulfan 0.509 / 0.203; lithium 0 / 0; ethanol 1 (Vmax) / 0.39; paracetamol 1 / 0.778; dexmedetomidine (obese vs lean) negative CL effect; **propofol 1 / 1** (Cortinez 2010); remifentanil rows (Egan 1998 obese vs lean, LBM by James) 0 (row alignment in the text layer is partly garbled).

## Pharmacodynamics and end points
None. No opioid PD values (remifentanil appears only as an Ffat example).

## Covariates
Size via NFM with drug-specific Ffat; maturation (sigmoid) separately for neonates and infants (Section 4). Negative Ffat estimates suggest organ dysfunction with obesity; then FFM as size plus an empirical fat effect may be preferable (Section 7).

## Caveats
Theoretical review; Ffat is acknowledged as empirical; several Table 1 entries are unpublished work. The authors' own propofol example shows that FFM alone is not always the right descriptor (Ffat = 1, i.e. total body mass).
