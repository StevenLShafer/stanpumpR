# Fediuk 2021b: ertugliflozin population PK in East/Southeast Asian and Chinese subgroups

## Study
Two separate re-analyses of the ertugliflozin population PK model of Fediuk 2021a (PMID_33205593, Clin Pharmacol Drug Dev 2021;10(7):696-706), to support registration in China and E/SE Asia (PDF p. 2-3).
- **Data set 1**: the *same* data set as the original analysis, 13,692 observations, 2276 subjects (15 studies), with race recoded as E/SE Asian (n = 154; Japanese phase 1 subjects, and Asian phase 2/3 subjects enrolled in Hong Kong, Korea, Malaysia, Philippines, Taiwan, Thailand) vs non-E/SE Asian (n = 2122; Asians enrolled at US/European sites count as non-E/SE).
- **Data set 2**: expanded, 16,018 observations, 2620 subjects (17 studies; adds a phase 1 study in healthy Chinese and the VERTIS Asia phase 3 study), three groups: Asian from mainland China (277), Asian from rest of world (382), non-Asian (1961).
- Table 1 (PDF p. 4): data set 1 weight 86.9 +/- 19.7 kg (42.6-197), E/SE Asian 69.7 vs non-E/SE 88.2 kg; age 55.7 +/- 11.6 y (18-87); eGFR 85.9 +/- 24.3 (6.8-196) mL/min/1.73 m2; 1287 men; 2084 (91.6%) T2DM. Data set 2 weight 84.7 kg; mainland China 70.5, ROW Asian 72.8, non-Asian 89.1 kg. (Source typo: data set 1 non-E/SE Asian men printed "208 (56.9)"; 1287 - 79 = 1208 and 1208/2122 = 56.9%.)
- HPLC-MS/MS, LLOQ 0.5 ng/mL (16 studies) or 0.1 ng/mL (1); BLQ removed. NONMEM, FOCE-I, methods as in the original analysis; full model estimation; bootstrap n = 1100.

## Model and parameters
Two-compartment, first-order absorption with lag time, first-order elimination; apparent parameters. Weight allometry fixed (0.75 on CL/F and Q/F, 1.0 on Vc/F and Vp/F). eGFR (MDRD; values above 120 set to 120) on CL/F. Reference subject: 65-year-old healthy man (non-E/SE Asian for data set 1, non-Asian for data set 2), 85 kg, eGFR 90 mL/min/1.73 m2, fasted (p. 3). Ethnicity parameterised as a fractional change with 0/1 indicators (p. 3). The final equations are in Table S3 (supplement, not read).

## Pharmacodynamics and end points
None modelled. Glycemic efficacy said to be driven by AUC at steady state; Vc/F changes affect Cmax only (p. 8). No therapeutic range.

## Covariates
Weight (fixed allometry), eGFR, T2DM, sex, ethnicity on CL/F; weight, age, sex, ethnicity on Vc/F; food on ka and F1. Derived effects stated in the text (p. 5-7): E/SE Asian CL/F +17% (AUCtau,ss ratio 0.855), Vc/F +148%; mainland China CL/F +4% (AUC 0.962), ROW Asian +8% (0.917); Vc/F +44% and +115%. Post hoc CL/F medians: E/SE Asian 10.4 vs non-E/SE 10.7 L/h; mainland China 9.42, ROW 9.51, non-Asian 10.1 L/h. Authors attribute the parity of post hoc CL/F to lower body weight.

## Caveats
- The E/SE Asian subgroup is 6.8% of data set 1; authors call this the main limitation.
- Covariate equations are in the supplement; the archive holds the article only. (supplement, 2026-10-27) Now archived
  and read (sup0001.docx Table S3).
- Age effect on Vc/F in data set 1 is imprecise (CI spans zero); in data set 2 it is -0.603 with a CI excluding zero, so the two data sets disagree on its size.
- Sponsor-authored (Pfizer/Merck).
