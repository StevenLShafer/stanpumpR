# Gentilini 2002: closed-loop alfentanil with MAP/plasma-concentration MPC

## Study
Design paper for an explicit model-predictive controller (MPC) that infuses alfentanil to hold MAP (invasive) near a reference and predicted plasma concentration near a reference. Includes a MAP artifact-rejection algorithm. Clinical test in 13 patients (3 shown, Figs 9-11; 49-, 48-, 37-year-old women, discectomy; p. 296-297). Premedication midazolam 7.5 mg; propofol induction, isoflurane maintenance; ~120 mL/h start for about 1 min, then control with plasma reference 100 ng/mL, MAP reference 70 mm Hg, plasma limits 0-400 ng/mL, MAP limits 60-120 mm Hg (p. 296). Syringe concentration 5e5 ng/mL (500 ug/mL); infusion u in mL/h (p. 290).
PK model choice: Scott, Scott weight-adjusted, Maitre, Hudson and "Shafer" (STANPUMP source code) were compared on a volunteer data set (ref 13); Shafer's set had the best MDAPE and wobble (results not reported, p. 291).

## Model and parameters
Three-compartment mammillary model, V1 = c * BSA (Eq. 7); BSA = 0.007184 * w^0.425 * h^0.725 (w kg, h cm; Eq. 8). Published c = 0.825; re-fitted c_opt = 1.1028 to remove over-prediction bias in their volunteers. Parameters (Table I, PDF p. 3 / printed 291, typical values used in the controller):

  - {name: k21, value: 0.142, unit: 1/min, source: "Table I"}

(Derived: BSA for 70 kg, 180 cm = 1.89 m2, so V1 about 2.08 L with c_opt, 1.56 L with c = 0.825; t1/2 ke0 = ln2/0.4 = 1.7 min.)

## Pharmacodynamics and end points
- ke0 = 0.4 /min (Table I), calculated to reproduce an "observed" tPeak = 1.5 min on MAP after an alfentanil bolus (PDF p. 3). The source of that tPeak is not given in this paper and the end point is MAP, not EEG or pupil. Computed for a 70 kg, 180 cm subject with Shafer's PK and c_opt.
- No MEAC or analgesic concentration is estimated. Controller concentration limits (0-400 ng/mL) and reference (100 ng/mL) are clinical settings, not effect thresholds; the steady-state tests used 100-300 ng/mL (plasma, model-predicted). The PD relation is explicitly an approximate model tuned to anesthesiologists' experience (no published alfentanil-MAP PD model).
- No equianalgesic or potency ratio.
- Assay: no concentrations measured in the patients.

## Covariates
Weight and height only, through BSA on V1. No age or sex effect.

## Caveats
MAP is a questionable analgesia end point (authors say so, p. 298). PD gain and ke0 are heuristic, not fitted. Only 13 patients, 3 shown, no statistics. Volume re-fit comes from the authors' own volunteer data set (ref 13), not shown here.

## Verification against stanpumpR
Not cited, so verdict not-applicable. Independent comparison with R/drugs_alfentanil.R: the library uses the Scott-and-Stanski set as printed by Shafer and Varvel 1991 (V1 2.1853 L at 70 kg; k10 0.0910, k12 0.656, k13 0.113, k21 0.214, k31 0.017 /min; R/drugs_alfentanil.R:13-35), with tPeak 1.4 min (line 40) and MEAC 39 (line 41). Gentilini's rate constants (above) are different (k10 0.0748 vs 0.0910, k12 0.515 vs 0.656), so the paper's "Shafer" set (from STANPUMP code, with V1 modified by their own re-fit) is not the library's set and must not be used to check it. The paper's tPeak 1.5 min (MAP) is close to the library's 1.4 min but is a different end point and a different PK set; the library's MEAC has no counterpart here. The library's V1 scales with fat-free mass, not BSA.
