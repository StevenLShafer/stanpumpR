# Leslie 2002: BIS closed-loop propofol sedation for colonoscopy

The PDF is a whole run of Anaesthesia Forum pages. Other contents (not pharmacology): Stone and Howell, a UK survey of common-gas-outlet use for supplemental oxygen at Caesarean section (215 of 262 questionnaires returned, 82%); Carnie, patient feedback questionnaire on pre-operative visits (835 patients); a CT-measured skin-to-epidural distance study (29 patients); dexamethasone for PCA-related nausea and vomiting (90 women, 8 mg IV vs saline). None relates to a stanpumpR drug.

## Study
16 patients (9 F, 7 M), age 60 (16) yr, weight 72 (11) kg, ASA I-III, colonoscopy, no sedative premedication, hyoscine 20 mg IV (PDF p5-6, printed 694-695). Propofol by plasma-targeted TCI using the Diprifusor PK set (Marsh reference 6); start target 2 ug/mL raised 0.5 ug/mL each minute until OAA/S = 3; the BIS at that point became the set point. Same Absalom PID system as Absalom 2002 (BIS every 5 s, target adjusted every 30 s). Performance by Varvel methods; offset = BIS minus set point.

## Pharmacodynamics and end points
End point: BIS against observer-rated sedation (OAA/S 0-5 scale, Table 1). Sedation target OAA/S 3 corresponded to BIS set point median 80 (75-85); the set point was lowered by 5 BIS units in six patients for inadequate sedation. Median OAA/S 3 (3-3 [2.5-4]); seven patients had OAA/S 2 for 25% (24-33) of control time. Eight of 16 moaned or moved; four recalled something. No ke0, t1/2 ke0, tPeak, EC50 or gamma was estimated; the Discussion only recommends effect-site targeting (ref 18, Struys 2000). No MEAC or analgesic concentration and no potency ratio (not an opioid paper; no opioid given).

## Covariates
None analysed.

## Caveats
n = 16 with no control arm; no opioid, so noxious stimulation of endoscope passage caused arousals; plasma-target TCI; only propofol targets (plasma) are reported, no measured concentrations.
