# Vashi 2023 (supplement): cenobamate covariate forms, covariate steps and final parameter table

## Study
The supplement to the Vashi 2023 short communication. The analysis pooled 960 subjects and 8700 concentrations
from eight phase 1 studies, two phase 2 trials and one phase 3 trial (see PMID_37429218.md). The supplement has
no new data. It contains:
- Supplemental Methods (p1): the covariate equations.
- Supplemental Table 1 (p2): the late covariate-modelling steps.
- Supplemental Table 2 (p3): the final model's estimates.
- Six diagnostic figures (p4-10): observed versus predicted, CWRES and VPC for the structural and final models,
  the last VPC by study.

## Model and parameters
- **Supplemental Methods, p1:**
  - Continuous covariates enter linearly: P_i = P_TV (1 + theta_X (X_i - X~)), where X~ is a summary statistic,
    "typically the median".
  - Categorical covariates enter as P_i = P_TV (1 + theta_Xm I_Xmi), with an indicator for category m. P_TV is
    the parameter's value in the first category.

## Pharmacodynamics and end points
None.

## Covariates
- **Two disagreements inside the supplement.** Both are recorded, and their cause is not guessed:
  - The Hispanic effect is accepted on V1/F in Supplemental Table 1 (runs 18 and 22) and rejected on CL/F
    (runs 19 and 23). Supplemental Table 2 labels it "Change in CL/F among Hispanics".
  - Supplemental Table 1's footnote lists weight on CL/F. Supplemental Table 2 has BSA on CL/F and no weight
    term on CL/F.
- **The dose effect** is called "exponential" in Table 2, while the Methods state only the linear form for
  continuous covariates. Its equation and reference dose are not given.
- **Covariate medians:** none is printed anywhere in the supplement.

## Caveats
- **Units printed in Table 2:** "m⁻²" on the dose row, the same as the BSA row; "IU" on the bilirubin row (an
  activity unit for a concentration); bilirubin's RSE as -9.69%.
- **IIV** is on ka, CL and V2. The table's footnote says it is derived as the square root of the variance.
- **Supplemental Table 1** starts at run 16, so the forward and backward steps before it are summarised only in
  its footnote.
- The diagnostic figures (p4-10) were not used for any number.
