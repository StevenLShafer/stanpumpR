# Kenna 2004: non-compliance measured with error (MPML)

## Study
Statistical simulation paper, not a pharmacology study. Setting: a trial where a cheap, biased compliance measure
(questionnaire, CQ) exists in all N subjects and an accurate one (electronic monitor, CM) in a random fraction fM.
Binary response Y; compliance C has 3 levels (0, 0.5, 1); two arms (Dn = 0 or 1), D = C*Dn; logit(P(Y)) linear in D
(printed p. 3566). N drawn from U(50,400), fM from U(0,1) by Latin hypercube; 500 simulated trials per study (4 studies),
plus a power study (study 5: fM 0.15, NP = 100 data sets, P(Y|D) = 0.3/0.5/0.7).
Methods compared: MPML (maximum penalised marginal likelihood, integrating over missing CM using a calibration model
P(CM|CQ)), BSR (believe self-report), BA (best available), CD (complete data, drop subjects without CM), ITT, and ALL
(everyone has CM, the benchmark). Real-data example: 34 HIV patients on protease inhibitors, 75 usable records
(Bangsberg 2000), unannounced pill count as the response; N = 75, NM = 15/25/50/60 (printed pp. 3573-3575).

## Model and parameters
No pharmacokinetic model. Penalty weights lambda1 = 0.5/3, lambda2 = 0.5/6; priors are uniform over categories (printed p. 3568).

## Covariates
None; compliance was not modelled from covariates (printed p. 3578).

## Caveats
Authors' own: assumes CM missing completely at random; biased if missingness depends on true compliance; confounding
not addressed; CM = C assumption (A2) probably untrue in practice but MPML was robust to it in simulation.
In study 5 ITT had higher power (0.74) than MPML (0.63) (printed p. 3572).
