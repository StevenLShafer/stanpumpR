# McCune 2014 supplement: estimated allometric exponents, random-effect correlations, alternative models (Tables S4-S6)

## Pharmacodynamics and end points
None (not an opioid). The only exposure end point is the Css therapeutic window 592-963 ng/mL used in Table S6.

## Covariates
Table S4 supports fixing theory-based exponents: CL 0.769 against 0.75 and V1/V2 0.984/0.948 against 1. Q's estimate (0.874) is further from the fixed 0.75 than the others.

## Caveats
- Large RSE on several correlations (CL–V1 BSV 114.7%).
- Table S6 refits the comparator models' structures to McCune's own data; it does not test their published parameter values.
- Only the overall comparison is significant (P 0.0002); no age band is.
