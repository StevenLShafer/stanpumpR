# Yan 2025: external evaluation of ten escitalopram popPK models

## Study
Retrospective single-centre external validation (Xi'an Mental Health Center, TDM data 2020-2023). 193 patients,
241 steady-state trough concentrations (sampled within 2 h before the next dose); 157 had one level, 28 two, 8 three
or more. Table 3: age 42.93 ± 17.67 (13-80) y, height 164.43 ± 7.91 cm, weight 61.13 ± 11.91 (34-105) kg, BMI
22.55, dose 14.70 ± 4.65 (5-20) mg/day. Assay HPLC-MS/MS, LLOQ 3.0 ng/mL. No CYP2C19 genotypes: all patients were
assigned the IM phenotype (Discussion). Missing covariates replaced by the source study's mean/median.
Ten models (Table 1/2) run in NONMEM 7.5 with all parameters fixed; individual predictions (IPRED) by MAP Bayesian
estimation using the observed levels, population predictions (PRED) without them. Acceptance: |median PE| < 30%,
RMSE ≤ 30%, NPDE normal.

## Model and parameters
No new model. Models evaluated (Table 2, as transcribed by Yan): M1 Liu 2024 (transit absorption); M2 Poweleit 2023
(CL 14.2 × CYP2C19 factor × BSA/1.73 × 0.758 if inhibitor, V 428, Ka listed as 0.892); M3 Liu 2022
(CL = 16.3 × (1 + 0.0077 × (AGE − 45)) × 0.847 if IM / 0.479 if PM; V 815 L; Ka 0.6); M4 Kim 2021 (2-cmt, lag);
M5 Weisskopf 2020; M6 Courlet 2019; M7 Akil 2016; M8 van Gorp 2012 (overdose, WinBUGS); M9 Jin 2010; M10 Jin 2009.

## Pharmacodynamics and end points
None modelled. Introduction cites SERT occupancy > 80% above about 20 ng/mL, AGNP range 15-80 ng/mL, and a
meta-analysis range of 20-40 ng/mL (refs 13-16, not this paper's data).

## Covariates
None estimated. Notes BSA (Poweleit) performed best; age-free paediatric model still predicted adults well.

## Caveats
Single centre, troughs only, no genotypes (everyone assumed IM, which biases every CYP2C19-dependent model).
Inclusion criteria say adults ≥ 18 y but Table 3 gives an age range 13-80 (internal inconsistency). Yan's Table 2
lists Poweleit's Ka as 0.892 /h (Poweleit's paper: 0.8 /h fixed; 0.892 is M1's MTT), so transcriptions in Table 2
should not be used as primary values.
