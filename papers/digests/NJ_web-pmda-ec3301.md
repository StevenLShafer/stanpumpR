# PMDA Medical Safety Information No. 51 (revised 2024): drug name mix-ups

Source note: this is a medication-safety bulletin about look-alike drug names, not a mitiglinide product document
(no package insert, interview form or review). It is the only file the registry links for mitiglinide. The document
does not print its own file URL (its header links the series index,
pmda.go.jp/english/safety/info-services/safety-information/0001.html), so that the archived file is
000272006.pdf rests on the archive's download record.

## Study
Not a study. Four pages: (1) a case of isosorbide mononitrate vs dinitrate confusion; (2) a table of similar
nonproprietary names with brand names and therapeutic categories (p. 2); (3) same ingredient, different indications
(salazosulfapyridine, zonisamide EXCEGRAN vs TRERIEF, drospirenone/ethinylestradiol, metformin METOGLUCO (as printed) vs Glycoran
generics with different maximum doses, tadalafil); (4) prevention strategies. Table data "current as of MM 202X".
