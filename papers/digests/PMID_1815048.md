# Verotta 1991: semiparametric analysis of non-steady-state PD data

## Study
Methods paper: estimate the steady-state relation between drug input rate and effect from effect (E) data alone,
using an effect-compartment-like variable X convolved with a unit-impulse-response L(t,a) and a cubic-spline PD
function (printed pp. 691-697). Three situations: (1) plasma concentration Cs measured; (2) input rate I(t) known, no
Cs; (3) only dose known (I = Dose*delta). L(t,a) = e^(-a1 t) * sum_k a_2k e^(-a_(2k+1) t) form, m = 0-2 chosen by Akaike
criterion; ordinary least squares; knots at sample quantiles of X, p < 0.5n (pp. 694-696).

Applications (digitised or reported data from other papers):
- Verapamil PR interval (Schwartz 1989 data): 20 subjects, infusion 0.15-0.22 mg/kg over 15 min. Model 1 (m = 0) alpha1 = 0.041 min^-1 for one typical subject; Model 2 (m = 1) alpha1 = 0.022, alpha3 = 0.11 min^-1; Model 3 (m = 1) alpha1 = 0.066, alpha3 = 0.11 min^-1 (p. 697). Counterclockwise hysteresis noted (p. 697). Table I (p. 697): Akaike-chosen m counts, models 1/2/3 average m 0.00/0.80/1.05.
- Simulation mimicking verapamil: Ce = 0.006 Cs convolved with an exponential, Emax PD 100 - 75*Ce/(300+Ce), 250 replicates, 10% error; Table II (p. 704) mean error in input rate causing 25/50/75% of effect: Model 1 best, Model 3 biased (e.g. X25 mean error 80.0%, X75 -30.3%) (OCR of table; not checked on image).
- Hydroxyzine wheal/flare, 0.7 mg/kg oral (mean 39.0 mg), 7 adults: wheal a1 = 0.012 h^-1, a3 = 0.71 h^-1; flare 0.011, 0.67 (p. 705).
- Flecainide 200 mg / verapamil 120 mg oral, 8 subjects (Holtzman 1989): PR a1,a3 0.694, 0.698 (flecainide), 0.640, 1.71 (verapamil), 0.583, 1.042 (together) h^-1; verapamil 120 mg scaled by 200/120 superimposes on flecainide 200 mg for PR (pp. 705-706). Ejection fraction values 0.519/0.519, 0.503/0.500, 0.514/0.515 (pp. 706-708).

## Pharmacodynamics and end points
Effect-site equilibration is represented by L(t,a), not a single ke0. No ke0, t1/2 ke0, tPeak or EC50 is reported as a
drug property; the example alphas above are drug-specific fit rate constants (min^-1 or h^-1 as stated) for verapamil
(PR interval), hydroxyzine (wheal/flare), flecainide/verapamil (PR, LVEF). Not an opioid paper (opioid audit: none).

## Caveats
Authors: identifiability worsens as knowledge of the input falls (cases 1 > 2 > 3); needs rich, frequent E data spanning
onset to recovery; assumes stationary, linear distribution, memoryless PD, single effect site (pp. 709-710). Example
data for hydroxyzine and flecainide/verapamil were read from published figures of other papers.
