# Jeong 2022: torsemide PBPK-PD model, urinary sodium as the end point

Torsemide is not a stanpumpR drug (registry-only), but the card keeps `drugs: [torsemide]` as the context file lists it.

## Study
Not a clinical study: a whole-body PBPK model (blood, lung, liver, kidney, GI tract, rest of body, oral depot, urine;
Appendix A, PDF p23-24) built from digitised published mean or median profiles (WebPlotDigitizer 4.5) and individual
bioequivalence data, mostly in men, sexes pooled (Section 2.1, PDF p2-3; data listed in Table S1, not in the PDF).
Software: Berkeley Madonna, S-ADAPT, Phoenix WinNonlin; tissue Kp predicted by Simcyp v21 (PDF p4-5). Hepatic
metabolism is Michaelis-Menten (Vmax, Km from human liver microsomes); Ka, Ke (gut loss), Ku (renal excretion), Vrb and
Qrb fitted; Fr (unbound fraction, human serum albumin in vitro) and Pr (plasma-to-blood-cell ratio, measured in RAT
blood) fixed from in vitro work (PDF p5). Healthy-adult model then extended by parameter substitution to CYP2C9 EM/IM/PM,
cirrhosis Child-Pugh A-C, CKD mild-severe and CHF NYHA II-IV (Sections 2.6.1-2.6.4, Tables 1-4, PDF p6-9).
Validation: visual check, RMSE (all < 100), AIC (all < 200), two-fold error on AUC0-inf, Cmax and cumulative urine
(all within 0.5-2), normalised sensitivity within +/-1 (Section 3.8, PDF p16-17).

## Pharmacodynamics and end points
- End point: urinary SODIUM excretion rate (mEq/h), driven directly by urinary TORSEMIDE excretion rate x (ug/h), a
  "simple direct effect" model (Sections 2.2, 3.1, 3.7, PDF p3, p9-10, p16). No blood pressure, no diuresis volume model.
- Equation as printed (rendered PDF p10): E = E0 + Emax / (1 + x/EC50)^P, the exponent P set OUTSIDE the parenthesis.
  Read literally with P < 0, E at x = 0 would be E0 + Emax and would rise without bound, which contradicts the paper's own
  definitions of E0 (basal) and Emax (maximum). A form consistent with those definitions is E = E0 + Emax / (1 + (x/EC50)^P)
  with P negative, which equals a standard sigmoid Emax with Hill coefficient |P| (2.13 healthy). This reading is my
  inference; the paper does not state it, and Figure S1 (the fits) is not in the PDF.
- Ratios the text quotes (PDF p9-10), each checked: Emax healthy/cirrhosis 1.61 (105.1/65.24 = 1.611), Emax
  healthy/CHF 1.26 (1.259), EC50 CHF/healthy 11.53 (3985/345.5 = 11.53). PD fit r >= 0.81, AIC 63.12-173.8 (PDF p10).
- No PD model for CKD: data stopped below about 400 ug/h, no ceiling seen (PDF p14-15); CKD PD later simulated with
  the healthy PD model (PDF p18).
- Hysteresis: counter-clockwise against plasma concentration after oral dosing, none against urinary excretion rate
  (PDF p16). No ke0. Not an opioid; no MEAC.
- Simulated headline results (model outputs, not measurements): 10-fold doses in cirrhosis/CHF give mean sodium excretion
  33.67 and 23.77 vs 31.97 mEq/h healthy (PDF p18); CYP2C9 phenotypes differ 1.17-1.20-fold in steady-state
  concentration and 1.08-1.22-fold in sodium excretion (PDF p17-18).

## Covariates
No population covariate equations: groups are handled by substituting physiological parameters (Tables 2-4) and, for
PD, separate parameter sets per disease group (Table 5). CYP2C9 by Vmax/Km per phenotype (Table 1). Cirrhosis Fr from
total protein: Fr,cirr = 1/[1 + (1 - Fr,h) x PTcirr/(PTh x Fr,h)] (PDF p7).

## Caveats
- Fitted to digitised group means from several studies, not individual data; Pr taken from rat blood.
- In vitro Michaelis-Menten metabolism, though the authors note in vivo PK is linear to 200 mg (PDF p5, p10-11).
- The PBPK parameter table (Table S2) is supplementary and not archived.
- Table 5's printed equation is internally inconsistent as typeset (above).
- PD for cirrhosis comes from CP-B only and for CHF from mild-moderate only; CP-A/C and severe CHF are extrapolated, and
  the model over-predicted severe-CHF observations (PDF p15).
